## 风险与未覆盖

- **旁白识别是字面规则**：换一种开头的旁白（如「Searching now…」以外的新说法）不会被识别，仍会发出。
- **生产历史**：生产库里查不到含这类旁白的机器人消息，更早的正文已被保留期清掉，无法确认此前是否发给过真实客人。
- **开头缺日期**：W-天气 有一次正文没提到「明天」或具体日期，属于模型输出浮动，本版没有专门处理；门禁会继续把关。

## 回滚

回滚代码到 `v1.54.0`，只重建 API 容器；本版无迁移。
