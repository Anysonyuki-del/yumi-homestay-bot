## 风险与未覆盖

- 照片公开可缓存 1 天：房间改为不展示后，已缓存的照片在客户端最多仍可见 1 天；照片编号不可猜测性不作为保护手段。
- 照片存储复用私有文件目录，每张不超过知识图片上限；未做缩略图，详情页一次加载全部照片。
- 知识条目原本为机器人配合关键词撰写，勾选展示前需逐条核对措辞。
- 「问管家」的企业 ID 与客服链接尚未填写，按钮当前只提示「客服暂未开通」。
- 未演练备份恢复到独立数据库。
