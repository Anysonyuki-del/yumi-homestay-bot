## 风险与未覆盖

- **门禁只测回复决策链路**：合并等待、出站队列、过时判定和企业微信投递，继续由集成测试和测试号收件兜底。
- **字面判定**：同义说法补得不全会造成误报；禁令只增不减。把不稳定场景移出不退步集合时，必须在基线文件的 `removed` 里写明原因。
- **采样浮动**：「3 次失败至少 2 次」仍有误报可能，允许重跑门禁。
- **成本与时间**：每次改回复逻辑的部署多出几分钟到二十分钟，以及几元 DeepSeek 费用；门禁使用生产配置里的密钥，密钥不离开容器。
- **店外状态判定用词表**：改述会漏，例如「外面有点凉飕飕的」；带时间指向的正常句子可能被删，有审核知识出处的句子保留。
- **中性说明的适用面**：以前被删空时回退成行程建议的问题，现在一律得到「这项信息暂时无法确认。」；这句话不告诉客人下一步做什么。
- **本机部署脚本不入库**：门禁的接入依赖本机这份脚本，换一台电脑部署需要同样修改。

## 回滚

只回滚代码到 `v1.39.16`，只重建 API 容器；无迁移，不恢复数据库。本机部署脚本的门禁接入与代码回滚无关，如需停用门禁，可在部署时使用跳过开关并写明理由。
