## 改动及依据

- `src/homestay_bot/static/theme.js::applyTheme / DOMContentLoaded`，`templates/components/ui.html::theme_selector` 与两个公共布局：原先只有经典主题，现在提供「经典／暖色」原生选择，CSS 前恢复本机偏好，同步浏览器 theme-color；存储写入失败提示「本次已切换，浏览器无法记住此选择」，资源失败或无 JavaScript 时仍保持经典可用。切换不提交业务、不清空草稿/选择/忙态。依据：用户「新增可切换主题」、开始指示及暖色主题 Spec F1/F2/F4。
- `src/homestay_bot/static/app.css::warm 角色 / 工作台 / 日历覆盖`：新增 v6 奶油分层、珊瑚动作、中文系统衬线标题；普通文字、危险操作、语义徽标与焦点使用达标颜色。指标说明和入口分占网格，六组日历回退与 color-mix 按主题令牌维护。依据：用户「内容区层次太少效果不足」「根据 DESIGN.md 设计 ui 和配色」「黑色太突兀」「就这样吧」，以及本地真实数据截图的重叠证据与配色公式检查。
- `DESIGN.md::双主题规范` 与 `docs/design/references/claude-design-analysis.md`：原始 getdesign 分析完整保留，根规范改为 YuMi 双主题、中文字体和可访问性约束。依据：用户要求采用 DESIGN.md，以及 Claude Spec 审查 T1–T9 的核实取舍；Spec、审查和 v3–v6 草图一并保留。
- `.impeccable/config.json::side-tab 文件范围例外`：检测器将共享 CSS 中经典/暖色日历“今天”定位线重复归因到两个布局。保留日期定位语义，仅这两个文件忽略该规则；不关闭其他规则。依据：检测输出的 `.cal__date--today` 及 `components/ui.html` 的日期/今天标签，复检四项已清除。此前字体忽略保留。
- `tests/browser/test_admin_theme.py::theme_site / 主题行为用例`：真实同源 HTTP、正式路由/会话门面、临时 SQLite 验证；既有批量装配补正式只读总览服务，日历资源测试按各主题自身令牌验算。无应用装配、依赖或后端业务变更。
