| 改动 | 依据 |
| --- | --- |
| 全部 | 用户原话「把测试号的消息和订单清空，而且应该有个清空按钮」 |
| 清空范围 | 生产只读查询：测试号（客户 62，标签「测试专用号」）有消息 207 条、订单 1 张、客诉复核 3 条、记忆 30 条、记忆来源 30 条、长期摘要 1 份、任务 5 条。记忆和摘要是从聊天提炼的，不清的话机器人仍会「记得」测试对话，所以一并清空；任务在任务页单独取消或归档，审计日志不删，这两类不清 |

## 风险与未覆盖

- **删除不可恢复**：只对带「测试专用号」标签的客户开放。如果给真实客人误打了这个标签，他的聊天记录和订单会被清空。点击前有二次确认；每次部署前有数据库备份。
- **已同步的真实订单**：百居易同步来的订单，清空后下次对账会被重新同步回来。清空只对手工或测试订单有长期效果。

## 回滚

回滚代码到 `v1.48.1`，只重建 API 容器；本版无迁移。已清空的数据只能从备份恢复。
