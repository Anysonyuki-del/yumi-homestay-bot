| 婉拒话术 | 1.53.0 测试号实测：客人只收到前半句（`1.53.0.md` 追加的验收） |

## 风险与未覆盖

- **只有管理员能看**：客户档案本来就只对管理员开放。值班的普通员工收到转人工通知后，点链接会被拒绝；需要的话另行放开。
- **图片不显示原图**：客人发的图片、机器人发的配图都只显示「[图片]」类标记，不在页面里预览。
- **正文保留期**：已按保留规则清掉正文的旧消息，只能看到时间和发送方。
- **生产页面需登录后目检**：我没有管理员账号，部署后请你打开一次对话记录页签确认。

## 回滚

回滚代码到 `v1.53.0`，只重建 API 容器；本版无迁移。
