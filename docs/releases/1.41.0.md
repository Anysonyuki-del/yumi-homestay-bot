## 风险与未覆盖

- **明文存储的风险**：数据库和备份里是明文的客人姓名、手机号、特殊要求。服务器或备份一旦泄露，这些信息会直接暴露。
- **合规**：长期明文保存、不设期限，按个人信息保护法需要有合法依据和保存期限说明，由经营者判断。
- **已清除的数据无法恢复**：以前被清空的对话正文，以及已到期清除的审批资料，本版恢复不了。
- **密文列仍在**：保留一个版本供回滚，下一版删除时单独发布。
- **与边界 Spec 的迁移编号冲突**：它规划的 `0028_knowledge_scope`、`0029_stay_confirmation` 需要顺延到 `0029`、`0030`。

## 回滚

回滚代码到 `v1.40.2`，只重建 API 容器：
- 旧版本只读密文列，本版同时写入了密文，数据照常可用；
- 新增的明文列留在库里，不影响旧版本；
- 不需要降级迁移。如需彻底移除明文列，先备份，再执行 `alembic downgrade 0027_knowledge_embeddings`。
