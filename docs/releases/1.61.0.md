## 风险与未覆盖

- **上线后第一次同步仍从头读一次**：表是空的。消息按编号去重；「结束聊天」事件有时间判断；「发送失败」事件本来就按重复回执设计过。
- **同步锁只在单个进程内有效**：目前只有一个 API 容器，没问题；以后多实例部署时要换成数据库行锁（代码里已用 `ponytail:` 注明）。
- **中途中断最多重放一页**：处理到一半中断时，未保存游标的那一页会再处理一次。

## 回滚

回滚代码到 `v1.60.1`，只重建 API 容器。新表可以保留，旧代码不读它；需要时再执行降级迁移删表。
