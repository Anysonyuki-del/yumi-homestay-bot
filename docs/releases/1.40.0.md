## 改动凭据

| 改动 | 依据 |
| --- | --- |
| 紧急后续固定答复、求助说法不联网 | 用户：「这种问题应该沉淀进知识库走固定回答，而不是联网搜索」；诊断证据：首次基线中 `EM-燃气连发` 3 次都回了活动推荐，本地实测「我们现在该怎么办」判为联网 |

| 问价流程 | 用户：「你做一个版本然后到时候和codex做的一起对比选优」；诊断证据：参考价不算依据（`a57afd2` 与 `618c1b1` 的时间线）、问价不强制、英文不开放，`PR-201`、`PR-EN`、`PR-最便宜` 3 次均未通过 |
| 回归工具补强、期望收紧 | 诊断证据：4 个场景的回复实际安全，是判定口径问题；替身比线上宽松 |

## 风险与未覆盖

- **紧急识别的误报**：现有词表有误报，例如设施咨询被判成燃气泄漏。误报后，客人的求助类后续也会收到处置答复，直到员工接手；其他问题照常回答。根本解决在边界补充 P10。
- **「紧急处置」知识**：真实知识库目前没有这类条目，上线后先用安全提示兜底。1.41.0「经验沉淀」会根据真实事件起草，管理员确认后启用。
- **参考价作为依据的放宽**：查到参考价后，与现有房态查询同样的放宽方式，可能替同一回复里的其他本店事实背书。边界 Spec 4.3 的逐项绑定更细，两版将用同一门禁对比。
- **问价多一次查询**：参考价工具合并了房态，每次问价多一次百居易调用。
- **问价不再转人工**：只问价格时由机器人按参考价回答，会话不再进入人工模式；讨价还价、折扣仍转人工。
- **回归工具版本要求**：运行器依赖本版新增的函数与线上执行器，只能测 1.40.0 及以后的版本。
