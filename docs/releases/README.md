# 发布变更记录

每次发版（升级版本号、打标签或部署）一份，文件名为版本号。CHANGELOG 面向使用者说明「变了什么」；这里面向接手者和审计，说明为什么改、依据是什么、怎么证明改对了。

每份记录包含：版本与范围、改动清单、改动凭据、验证证据、风险与未覆盖、回滚。未执行的验证写明「未执行」与原因。记录与事实不符时在原文件追加带日期的更正，不改写原结论。不写密钥、服务器地址、本机路径、客户隐私和生产消息原文。
