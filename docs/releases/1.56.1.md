## 改动凭据

| 改动 | 依据 |
| --- | --- |
| `raw_limit` 改为 0 | 1.56.0 测试号验收：转人工的「能便宜点吗」落在最近 3 条里，接手要点没有它；手动重新整理也没变化（见 `1.56.0.md` 追加的验收）。「接手要点」的用途正是让员工接手转人工时看到原因，用户已要求「直接全部做完」 |

## 风险与未覆盖

- 每次整理都会带上最新几条消息，模型输入略长；摘要本身限 3 行，影响很小。
- 回复模型的上下文里，最近原文和摘要可能说同一件事。

## 回滚

回滚代码到 `v1.56.0`，只重建 API 容器；本版无迁移。
