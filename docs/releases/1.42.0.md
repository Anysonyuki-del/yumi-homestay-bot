## 风险与未覆盖

- **回复行为变化面大**：「退款政策是什么」「提前入住有什么规定」这类问题不再转人工，改用知识回答；联网失败不再转人工。上线后要留意有没有该转没转的。
- **知识范围按规则迁移，可能标错**：请管理员用复核清单逐条看一遍。标成「公开」的条目只在客人问周边时才用。「紧急处置」类条目落在「通用」里，紧急后续答复照常可用。
- **住宿确认多了一步**：客人问「我房间的……」时要先确认本次住宿。
- **53 个历史未通过场景仍在**：包括 `PI-折扣`——「能打五折吗」「可以打个折吗」不转人工。这是讲价词表的老问题，1.41.0 也一样，本版没修。
- **没有覆盖的**：真实 Hostex、企业微信、订单核对和员工通知的端到端流程，要靠测试号实际收件验收。

## 回滚

回滚代码到 `v1.41.0`，只重建 API 容器：
- 新增的列都有默认值或可为空，旧版本读写不受影响；
- 旧版本不看知识范围，全部已启用知识照常使用；
- 回滚不需要降级迁移。如需移除新增列，先备份，再执行 `alembic downgrade 0028_guest_plaintext`。
