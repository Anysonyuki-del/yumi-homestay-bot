## 改动凭据

| 改动 | 依据 |
| --- | --- |
| 文案开头 | 用户原话：「人工点击交还后客户那边应该立刻显示智能助手接入」。测试号实测（未给客人发消息）：结束会话后改为智能助手接待，被拒（95013）；人工接待直接改为智能助手接待，也被拒（95016）。平台只在客人下一条消息时才自动回到机器人接待，因此改为用提示文字来体现 |

## 风险与未覆盖

- 客人要等发出下一条消息，会话才会真正回到机器人接待；在那之前，企业微信管家那边显示「聊天已结束」。

## 回滚

回滚代码到 `v1.58.3`，只重建 API 容器；无迁移。
