# 1.79.0 发布变更记录

当前状态（2026-11-28）：本地实现、全量离线验证与 AOCI 对齐已完成，已获用户「提交部署吧」授权，准备提交、打标签并部署；提交号、标签与部署核对结果于部署后补记。

- **基线**：前一正式版本 `v1.78.0`（`8daf96a`），当前主线提交 `d0e71a3`。
- **依据**
  - 1.78.0 上线后用户反馈配色与质感不满；随后针对黑曜钴蓝 + 玻璃光效候选交付完成独立只读审查（`docs/reviews/2026-11-28_claude-to-gemini-obsidian-cobalt-glass-delivery-review-handoff.md`、`docs/reviews/2026-11-28_gemini-to-claude-obsidian-cobalt-glass-delivery-review.md`），定位 2 项 P1（暗色合成对比度跌破 4.5:1 且测试存在 RGBA alpha 盲区；棱镜 `::before` 缺 `@supports` 保护）、5 项 P2 与 3 项 P3。
  - 经过三轮真实页面浅暗渲染对比（3 套配色 → A2-Pro 质感精修 → 3 款高定按钮精修），用户明确拍板 **A2-Pro + 1A（象牙瓷白 × 曜黑银刃 · 刀锋银刃曜石键）** 并指令直接实施；在本地预览实时页面后，用户 2026-11-28 明确授权「提交部署吧 不用看了」。
  - 最终规格见 `docs/specs/2026-11-28_optical-prism-visual-redesign-spec.md` §9.5 与 `DESIGN.md` v3.2。
- **参考项目边界**：美学灵感来自 `RMvdesi/obsidian-prism`（GPL-3.0）公开 README 理念；全部 CSS、HTML、静态噪点图、图标重绘、测试与文档均在本仓库独立编写，不含参考项目任何源码或素材。
- **迁移、依赖与配置**：均无变化。未修改任何后端 Python 业务逻辑，未放宽 `EMPLOYEE_CSP`，未引入前端构建链，`layouts/auth.html` 保持零加载 `admin.js`。
