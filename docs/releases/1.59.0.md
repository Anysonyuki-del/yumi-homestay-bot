## 改动凭据

| 改动 | 依据 |
| --- | --- |
| 全部 | 2026-09-30 测试号：客人发「武汉最近有啥玩的，天气咋样」，回复只有天气，开头写「您问的"天气咋样"，我按今天和明天两天……给您答复」，明天气温写「15～21℃（也有预报口径为16～22℃）」，结尾两处主动询问，再加系统时效说明。用户原话：「不仅是天气和玩法，改动应该适用于所有同类情况。」 |
| 丢句根因 | 小句分类实测：「武汉最近有啥玩的」「附近有什么好吃的」「几点退房」都判为不联网，「天气咋样」「黄鹤楼门票多少」判为联网；提前返回的条件只放行服务或交易类剩余问题 |

## 风险与未覆盖

- 混合提问多一次模型调用，排在联网搜索之后，回复会慢 1～2 秒；多组联网是并行的，不额外增加时间。
- 联网之外的问题由模型按常识或知识库回答。像「最近有啥玩的」这类带「最近」的，并不会去查实时活动。
- 提示词的约束依赖模型遵守，由门禁新场景和测试号验收检验。
