- N-05：只有「表单已标记提交、按钮要等 0 ms 定时器才标记」这段空档是真问题；页面上没有重置按钮，不需要监听 `reset`。

## 风险与未覆盖

- **CSP 收紧**：以后后台引入外部字体、图片或第三方脚本时，必须先在 `middleware.py::EMPLOYEE_CSP` 加来源，否则浏览器会拦下。Tauri 桌面端加载的是同一批后台页面，客户端没有注册任何 IPC 能力，不受影响；Windows WebView2 上的实际表现未单独验收。
- **生产页面**：部署后需在登录后的页面上确认没有 CSP 报错，见部署记录。
- **零引用类判断**：以模板、脚本、Python 源码为准，排除了模板里动态拼接的修饰类（如 `badge--{{ tone }}`）。
