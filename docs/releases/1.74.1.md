## 风险与未覆盖

- **Secret 没被验证就可能生效**：企业微信可能在获取 token 这一步就返回 60020。这时 Secret 没被验证，填错也会被放行，要等配好可信 IP 后轮询报认证失败才暴露。代码旁有 `ponytail:` 注释说明这个天花板和升级条件。
- **放行到配好 IP 之间收发不了消息**：这段时间机器人收发不了消息，企业微信轮询会按退避节奏记录告警。
- **提醒不会自动消失**：标记跟着生效版本走。配好可信 IP 后要重新测试保存一次，提醒才会消失。
