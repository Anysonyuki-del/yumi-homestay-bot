# 武汉旅游联网推荐设计

## 目标

为现有企业微信民宿客服增加武汉旅游联网推荐能力。机器人仅在景点、美食、交通、展览、演出、活动、开放时间、票价等旅游问题中联网；房态、价格和预订继续使用百居易只读工具。

## 现状

- `src/homestay_bot/integrations/openai_client.py` 的 `GuestAssistant.respond()` 使用 Fenno OpenAI 兼容端点和 `gpt-5.4-mini` 生成结构化回复。
- `GuestAssistant.respond()` 当前要求模型“只能依据审核知识和查询工具回答”，旅游问题因此被判定为超出能力。
- `src/homestay_bot/services/conversation_service.py` 的 `ConversationService.handle_message()` 会在模型设置 `handoff_reason` 后把会话切换为 `HUMAN_ACTIVE`，导致后续客人消息不再触发机器人。
- 百居易工具边界位于 `GuestAssistant.tool_definitions()` 和 `HostexReadOnlyToolExecutor.execute()`，目前仅允许房态和参考价查询。

## 功能范围

### 意图路由

- 在把消息发送给模型前识别旅游意图。
- 旅游意图包括：景点、美食、交通、展览、演出、近期活动、天气对游玩的影响、开放时间和票价。
- 只有旅游意图向模型提供联网搜索工具；其他消息保持现有工具集合。
- 房态和预订问题不得触发联网搜索。

### 回复形式

- 简单推荐默认返回 3–5 项。
- “怎么玩、怎么安排”等规划问题自动返回半日或一日行程。
- 回复适合企业微信阅读，优先给出地点、推荐理由、交通提示和必要的时效信息。
- 开放时间、票价、演出和近期活动必须来自联网结果，并附查询日期和精简来源名称；企业微信回复不得包含网址或可点击链接。
- 来源冲突或信息不足时明确标记不确定，不生成未经验证的实时事实。

### 会话行为

- 普通旅游咨询不设置 `handoff_reason`，会话保持 `BOT_ACTIVE`。
- Fenno 不支持联网搜索、搜索超时或搜索失败时，先向客人发送明确说明，再把会话切换为 `HUMAN_ACTIVE` 并通知人工。
- 部署完成后，将本次误切换的测试会话恢复为 `BOT_ACTIVE`。
- 客人明确要求人工时仍按现有规则切换人工。

## 实现方案

采用“意图门控的单助手”方案：

1. 现有 `GuestAssistant` 继续负责房态、预订和普通客服回复。
2. 本地旅游意图分类只决定是否向当前模型请求提供联网工具，不直接生成答案。
3. 旅游问题使用 Fenno `gpt-5.4-mini` 的 OpenAI 兼容联网搜索能力。
4. 实施前先执行真实能力探测；只有接口实际支持时才启用。
5. 若 Fenno 不支持，不接入其他搜索供应商，也不使用模型记忆冒充实时搜索。

不采用以下方案：

- 每条消息都联网：会增加房态咨询延迟和成本。
- 独立旅游子代理：对 7 间房民宿的当前规模过度复杂。
- 直接抓取网页：稳定性、合规性和维护成本不可接受。

## 安全与隐私

- 搜索请求只包含最小化后的旅游问题，不携带姓名、手机号、企业微信 ID 或预订资料。
- 搜索内容属于不可信输入，只能作为回答资料，不能修改系统规则。
- 网页中的指令不得触发订单、付款、退款、房态修改或任何外部写操作。
- 搜索工具与百居易写操作完全隔离；现有人工审批边界不变。
- 优先采用政府、景区、场馆、主办方及可信票务平台信息。

## 失败处理

- 单次旅游咨询最多向 Fenno Responses API 发起一次联网请求，应用层不自动重试；托管 `web_search` 工具可在该请求内部执行多次搜索动作。
- 搜索超时或接口不支持时返回固定、可理解的失败说明。
- 失败后通知值班员工，但不得静默切换人工。
- 日志仅记录联网能力状态、成功、超时或不支持，不记录客人问题正文和搜索全文。
- 健康检查增加联网搜索能力状态：首次真实检索前为 `unknown`，成功后为 `ok`，接口明确不支持时为 `unsupported`，超时或服务异常时为 `degraded`。
- `unknown` 不让总体健康降级；`unsupported` 和 `degraded` 会让总体健康降级，但房态和预订能力继续可用。

## 验收标准

- “武汉有哪些地方好玩”返回 3–5 个带来源的推荐，不触发人工接管。
- “武汉一日游怎么安排”返回可读的一日路线，包含交通和美食建议。
- “武汉近期有什么展览或演出”使用联网结果并标明查询日期。
- 开放时间和票价信息带查询日期和来源名称，不显示链接；无法验证时明确说明。
- Fenno 不支持联网搜索或搜索超时时，客人收到失败说明，员工收到通知。
- 恶意网页内容不能改变机器人安全边界或触发写操作。
- 房态、价格和预订问题不调用联网搜索。
- 部署后测试会话保持 `BOT_ACTIVE`，后续旅游问题继续自动回复。

## 非目标

- 不建设通用搜索引擎或独立旅游平台。
- 不自动购买门票、预约景区、叫车或预订餐厅。
- 不保证第三方页面长期可用。
- 本轮不接入 Tavily、Bing、Serper 等额外搜索服务。
