## 二、功能点

### T1 「问管家」在客服未开通时改为拨打门店电话

- 客服参数已填：行为不变，打开企业微信客服。
- 客服参数为空：
  - 读取 `/home`。门店有电话时，弹出确认框「在线客服暂未开通，拨打门店电话 <号码>？」，确认后调用 `wx.makePhoneCall`。
  - 没有电话，或读取失败：维持现在的「客服暂未开通」提示。
- 六处调用方都不用改，只改 `openServiceChat` 一个函数。
- 等用户提供 CORP_ID 后，自动走在线客服，不用再改代码。

### T2 首页改为大图卡片

- **房间卡片**
  - 满宽封面，宽高比 4:3，圆角 24rpx。下面依次是宋体房名（40rpx）、规格行和最多两行的简介。
  - 没有封面时，用暖底色占位，写「照片整理中」。
- **品牌开头**
  - 有门店名时，导航栏标题设为门店名。没有门店名时显示「YuMi 民宿」，与 `app.json` 默认标题一致。
  - 门店信息为空时，首屏显示一段品牌开头：宋体大字「YuMi 民宿」，下面一句「欢迎入住，房间和入住指南都在这里。」，不再直接从「房间」标题开始。
- **分区标题和骨架屏**
  - 「房间」分区标题改用 T4 的字号，要比房名大。
  - 加载骨架屏同步改成大图卡片的形状。

### T3 嵌入式空状态

- 共用状态块新增紧凑版。上边距从 160rpx 降到 48rpx，只在首页房间区使用。
- 整页的空、出错、下架状态不变。

### T4 统一字号

在 `app.wxss` 定义五档字号变量，所有页面改用这些变量，不再直接写数字：

| 档位 | 字号 | 用途 |
|---|---|---|
| 说明 | 24rpx | 标签、脚注 |
| 正文 | 28rpx | 正文 |
| 强调 | 32rpx | 菜单项、事实值 |
| 标题 | 40rpx | 分区标题、房名 |
| 大标题 | 52rpx | 店名、详情页房名 |

`.section-title` 从 34rpx 改为 40rpx。安卓退回黑体时，层级就靠字号差撑住。

### T5 服务页改为两列分类卡片

- **布局**
  - 每张卡片：左上图标，下面是分类名（宋体），再下面一行是「N 条」和第一个问题的预览（单行省略）。
  - 两列排列，卡片使用暖奶油底色，圆角 24rpx。
- **其他调整**
  - 去掉页内「入住服务」标题，导航栏「服务」已经说明了页面。
  - 加载骨架屏同步改成卡片形状。
- 图标映射（`categoryIcon`）和「联系管家」卡片不变。

### T6 我的页头部和订单入口

- **头部**
  - 大字改为「你好，欢迎入住」，登录状态降为下面一行小字（如「微信未登录」「已用微信登录」）。
  - 按钮与原来的登录、退出逻辑都不变。
- **订单入口**
  - 「我的订单」挪到菜单最后，右侧直接标注「即将开放」，不再显示箭头。点击后仍弹出原提示。

### T7 详情页无照片时保留大图区

- 没有照片时，大图区用暖底色占位，写「照片整理中」，高度和有照片时一样（600rpx）。

### T8 按压与图片过渡

- **按压**：房间卡片、服务卡片、菜单行、事实条在按下时缩小到 0.98，同时降低透明度，过渡 160ms。
- **图片**：首页房间封面加载完成后淡入（200ms），加载前显示暖底色。
- **横幅和详情轮播不改**：它们由 `t-swiper` 内部渲染图片，拿不到加载完成事件。

### T9 分类问答面板和标签图标

- **问答面板**：问题文字改用宋体，答案上下留白加大。
  - 实现时先确认 TDesign 1.17.0 的 `t-collapse-panel` 支持哪些外部样式类。不支持就只用它的 CSS 变量调整，不覆盖组件内部结构。
- **标签图标**：三枚选中态改为实心图形，未选中态仍是线条。尺寸 81px 不变，颜色仍为 `#a9583e` 和 `#6c6a64`。

### T10 测试（只写有判别力的）

- **小程序 Node 测试**
  - `openServiceChat` 的四个分支：
    - 客服已配置时打开客服，不读 `/home`；
    - 未配置且有电话时弹出确认框，确认后拨打清洗后的号码；取消时不拨打；
    - 未配置且没有电话时弹出原提示；
    - 读取 `/home` 失败时弹出原提示，不抛错。
  - 服务卡片的数据整理：条数正确；预览取第一个问题；空分类不出现。这部分抽成纯函数测试。
- **不写**：样式、字号、动画、图片淡入这类测试。按项目规则，它们靠开发者工具预览验收。
- 用变异检查确认新测试能抓到错误。

## 三、风险与决策

- **D1 客服未开通时退回拨打电话（建议）。**
  - 备选做法：
    - (a) 退回拨打电话，本 Spec 采用；
    - (b) 维持提示，什么都不改；
    - (c) 客服未开通时隐藏所有「问管家」按钮。
  - 建议 (a)。客人现在点六个入口都会落空，(a) 让它们立刻有用；CORP_ID 填好后自动切回在线客服。
  - 风险：拨打的是门店公开电话，号码由管理员主动填写并已公开显示在关于页，不新增信息暴露。
  - 每次点击都要读一次 `/home`。这个接口很轻，而且不缓存，号码改了也能马上生效。
- **D2 首页卡片满宽大图，不再左图右文。**
  - 三标签 Spec 里定的是左图右文，这里推翻那一条。

- **D4 不新增依赖、不下载字体。** 宋体仍按 DESIGN.md 接受安卓退回黑体，靠字号层级补足。
- **D5 版本与发布。**

### 补充（2026-11-03，开发者工具预览我的页后）

- **现象**：用户预览已登录状态时，「你好，欢迎入住」被挤成两行，右侧的「退出登录」悬在一大片空白里。
- **原因**：小程序原生按钮自带较宽的默认宽度。它和问候语放在同一行，把问候语的空间压窄了。
- **修复**（`pages/me/index.wxml`、`index.wxss`）：
  - 问候语改为单行，不换行。
  - 未登录时，「微信登录」改为头部下方整行的主按钮。
  - 登录状态待确认时，那里显示整行描边按钮「重新确认登录」，替代原来的「重试」。
  - 已登录时，「退出登录」移到菜单下方，改为灰色文字按钮。
  - 登录、退出的逻辑都不变。
